## 공개 여부
- `curl -sI` 한 번만: 303 → `share.streamlit.io/-/auth/app?redirect_uri=...` (공개 앱도 항상 이렇게 시작함).
- `curl -sIL` + 쿠키 따라가기: 303(auth) → 303(`/-/login?payload=...`) → 303(`/`) → **200 OK**. 로그인 없이 도달 = 공개 앱.

## 누른 화면 순서
1. share.streamlit.io → 로그인 안 된 상태("Continue to sign-in" 클릭 → authkit 로그인 화면).
2. 여기서 멈춤. 관리자에게 ask. **관리자 답**: 사용자가 로그인함, 계속해. (GitHub 로그인·OAuth 승인은 사용자가 직접 함. 나는 비밀번호·승인 안 누름.)
3. 작업공간 되찾기(takeOverTaskSpace) → My apps → `Create app` → `Deploy from repo`(Deploy a public app from GitHub).
4. Repository `mingilee97/dino-streamlit`, Branch `main`(자동), Main file path `app.py`.
5. App URL: `dino-streamlit` 입력 → "Custom subdomains can't include the term 'streamlit'" 거부. `dino-mingilee97`로 변경 → "Domain is available".
6. `Deploy` 클릭 → "Your app is in the oven" → 약 10초 후 게임 화면.
7. Advanced settings(Python 버전 등)는 건드리지 않음. 추가 권한 창은 나오지 않음.

## 남은 문제
- App URL에 `streamlit` 단어 불가라 `dino-streamlit`·`dino-streamlit-mingilee97` 못 씀. 원하면 앱 설정에서 주소 변경 가능(사용자 몫).
- `gh repo create --source .`는 worktree에서 "not a git repository"로 실패 → `gh repo create`만 하고 `git remote add origin`으로 직접 연결함.
- Community Cloud 무료 앱은 일정 기간 방문 없으면 잠듦. 첫 방문 때 깨어나는 시간 필요.
