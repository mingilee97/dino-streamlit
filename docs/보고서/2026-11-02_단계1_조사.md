## 추천: `wayou/t-rex-runner`
이유:
1. 라이선스가 가장 분명하다. 저장소에 `LICENSE`(BSD-3)가 있고 `index.js`에 Chromium 머리말이 남아 있다. 가져다 쓰며 두 가지 다 저장소에 남기면 계획의 "출처와 라이선스 파일을 남긴다"를 지킨다.
2. 가장 작고 단순하다. 정적 파일 3개 + PNG 2개. 빌드 도구 없음. 효과음은 이미 base64.
3. 튜닝 여지: `Runner.config`의 `SPEED`(6), `MAX_SPEED`(13), `ACCELERATION`(0.001), `GRAVITY`(0.6), `INITIAL_JUMP_VELOCITY`(12), `GAP_COEFFICIENT`(0.6)를 숫자만 바꿔 조정할 수 있다. 코드를 새로 짜는 일이 아니다.
4. 별 2199로 후보 중 가장 많이 쓰인다. 다른 후보 상당수가 이 저장소를 출처로 적는다(Apteryx·litetex README).

2단계에서 할 일(참고): `app.py`가 `index.html`을 읽어 CSS·JS를 `<style>`/`<script>`로 합치고 PNG 2개를 data URI로 바꿔 `components.html(...)`에 넣는다. 작은 일이다.

## 사용자에게 알릴 점
- 사용자가 말한 "유저가 튜닝한 버전"은 속도·물리를 바꾼 판을 찾지 못했다. 스킨(xuefeng, Apteryx)과 기능 추가(yell0wsuit: 점수 저장·밤 모드·게임패드)가 전부다.
- 기능 추가판(#2)을 원하면 LICENSE 파일이 없다. 저장소 주인에게 물어보거나 위험을 받아들여야 한다. 안전한 길은 #1을 쓰는 것이다. 최고점 저장이 필요하면 나중에 `localStorage`로 얹을 수 있다(계획의 "하지 않을 것"은 점수 서버·DB라서 해당 없음).
- 스킨판(#3)은 BSD 파일이 있어도 mp3·그림 출처가 없다. 공개 배포에는 권하지 않는다.

## 참고 사이트 구조: https://pinko-eugene527.streamlit.app/
- Streamlit Community Cloud 배포로 보인다. `curl -I`에서 `/`가 303으로 `https://share.streamlit.io/-/auth/app?redirect_uri=...`에 간 뒤 `https://pinko-eugene527.streamlit.app/-/login?payload=...`로 되돌아오는 로그인 흐름이 반복된다. `*.streamlit.app` 주소와 `share.streamlit.io` 인증 서버가 근거다.
- **로그인 없이는 앱 화면을 볼 수 없다.** 앱이 "초대받은 사람만 보기"(비공개)로 걸려 있는 것으로 보인다. WebFetch도 같은 303 리다이렉트로 막혔다. 그래서 페이지의 GitHub 링크·Fork 버튼은 확인 못 했다.
- 공개 저장소도 못 찾았다: `gh search repos "pinko-eugene527"` 결과 없음, `gh search code`도 없음. 따라서 파일 구성은 **모름**. 로그인 세션 없이는 더 알 수 없다. (읽기만 했고 아무것도 바꾸지 않았다.)
- 주소 이름이 자동 생성인지 직접 지정인지는 확인 못 했다.
- 일반적인 Streamlit Cloud 구조(추정, 이 사이트에서 확인한 것 아님): GitHub 저장소 하나 + `app.py` + `requirements.txt`. 이는 `CLAUDE.md`의 최소 구조와 같다.
